## Finding

`check_operator_inline_policies` reads `PolicyDocument` directly (`deploy/check/template_check.c:2174-2181`). An `Fn::If`-wrapped `Policies[*]` element, or a `Policies` value supplied as an intrinsic, has no direct `PolicyDocument` key and is silently skipped, so D9's inline operator-policy scan fails open for those shapes instead of rejecting them.
