## Finding

`UserToGroupAddition.GroupName` is resolved only when it is a `!Ref` (`deploy/check/template_check.c:1945-1949`). A literal group name is not mapped back to its `AWS::IAM::Group` resource, so the CI user's membership in that group is not discovered and the group's attached policies escape rule 4.
