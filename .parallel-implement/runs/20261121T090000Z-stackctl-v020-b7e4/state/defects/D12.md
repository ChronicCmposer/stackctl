## Finding

`check_artifact_reader_policies` (`deploy/check/template_check.c:1656-1658, 1666-1687`) only iterates top-level `AWS::IAM::ManagedPolicy` / `AWS::IAM::Policy` resources. `AWS::IAM::User.Properties.Policies` on the `<project>-ci` user is never scanned. An inline policy on the CI user can therefore grant `s3:PutObject`/`s3:DeleteObject` on the own object ARN, or `s3:GetObject` on another project's bucket, and the runtime fail-closed `TEMPLATE_OVERRIDE` gate accepts the template, bypassing CONTRACT rule 4.
