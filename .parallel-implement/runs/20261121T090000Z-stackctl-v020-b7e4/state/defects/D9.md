## Finding

Operator INLINE policies outside rule 1/2 scope. `collect_operator_policies` (`deploy/check/template_check.c:1711-1736`) only collects resource-level `AWS::IAM::ManagedPolicy`/`AWS::IAM::Policy`; `check_operator` (`:2165-2168`), `check_operator_user` (`:1763-1769`), and `check_iam_node` (`:1006-1030`) never apply the own-bucket rule 2 to `AWS::IAM::User.Properties.Policies`. An operator user carrying an inline policy can therefore grant S3 access outside the own bucket without a violation. Pre-existing, not introduced by attempt 3.
