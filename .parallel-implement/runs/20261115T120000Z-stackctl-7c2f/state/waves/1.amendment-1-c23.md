# Amendment 1 — C23 rewrite of wave-1 artifacts

Operator-authorized contract amendment. All stackctl-authored C now compiles as
C23 (`-std=gnu23`); vendored upstream sources keep their existing flags. No
vendored upstream source was modified, and no file outside the operator's scope
was touched. `logs/*` was not touched.

## Notes

- Baseline `bazel test //core/crypto:crypto_test` failed to link before this
  amendment with `relocation R_AARCH64_... cannot be used against symbol
  '__stack_chk_guard'; recompile with -fPIC` — a pre-existing static/PIC issue,
  not a C23 issue. The same static-linking convention already used by
  `core/config` was applied to `core/crypto`, and the test now passes.
- C23 is fully supported by both the system compiler (gcc 16.2.0 and clang
  21.1.8) and the Bazel hermetic zig-cc toolchain for stackctl-authored code.
