### Gaps found and filled

1. `config_arch_list` — only the amd64 branch was asserted; arm64, the two-element
   `both` list, and the NULL-config guard were untested. Added `test_arch_list_variants`.
2. `config_build_working_directory` — exercised only transitively; added direct
   assertions for non-empty (returned verbatim), empty (NULL), and unset (NULL).
3. envfile enumeration — `config_envfile_key_at`, `config_envfile_value_at` were never
   called directly, and `config_envfile_count(NULL)` was untested. Added
   `test_envfile_enumeration` asserting insertion order, past-end NULL, absent-key NULL,
   and NULL-handle guards.
4. envfile failure paths — missing file, NULL path, invalid key name, and over-long key
   were untested. Added `test_envfile_errors`.
5. `sigv4_sign` — the `x-amz-security-token` signed-header branch and the NULL-argument
   `-EINVAL` guards were untested. Added `test_sigv4_session_token` (exact Authorization
   header independently derived from the SigV4 spec) and `test_sigv4_invalid_args`
   (NULL service / NULL host / NULL out each return `-EINVAL`).

All new tests pass against the unmodified implementations (the implementations were
already green). RED evidence for these suites is the retroactive mutation check below.
