## (i) Correctness vs contract — PASS

- Service headers expose the frozen surfaces: `cfn.h`/`ec2.h`/`s3.h`/`ssm.h`
  operations, lifecycle/destructors, status enums, and waiters are present and
  match the CONTRACT "Required surface" list.
- CloudFormation change-set lifecycle, including idempotent DeleteChangeSet
  (`core/cfn/cfn.c:1494-1537`), stack delete (`core/cfn/cfn.c:1668-1688`), and
  waiters that turn terminal failure into `ECANCELED`
  (`core/cfn/cfn.c:1997-2078`). `REVIEW_IN_PROGRESS` is present in the stack
  status table (`core/cfn/cfn.c:590`, `core/cfn/cfn.h:104`) and excluded by
  `cfn_stack_status_is_in_progress` (asserted in `core/cfn/cfn_test.c:328-350`).
- EC2 launch invariants: Min=Max=1, ClientToken, instance-only
  `TagSpecifications` with Project + Name + `stackctl:launch-nonce`
  (`core/ec2/instances.c:123-155`); encrypted + `DeleteOnTermination` root EBS
  (`core/ec2/instances.c:126-134`); spot one-time with no MaxPrice
  (`core/ec2/instances.c:136-145`); `IamInstanceProfile.Name`
  (`core/ec2/instances.c:122-123`).
- S3 path-style addressing and `UNSIGNED-PAYLOAD` (`core/s3/s3.c:452-455`),
  bucket subresource coverage, S3 XML error-code mapping
  (`core/s3/s3.c:328-375`), and the sha256 read-back helpers
  (`core/s3/s3.c:703-762`).
- SSM JSON-1.1 requests carry signed `X-Amz-Target` + Content-Type extras and
  set `content_type = NULL` to avoid a duplicate header
  (`core/ssm/ssm.c:162-229,183-195`).
- CLI: frozen exit-code enum, stdout/stderr split (`core/cli/common/cli_output.c:26-63`),
  argv parser, confirmation rule (`core/cli/common/cli_output.c:205-241`),
  secret redaction (`core/cli/common/cli_output.c:288-357`), lock policy
  (status lockless) (`core/cli/common/cli_ctx.c:89-102,200-202`), and signal
  handling (`core/cli/common/cli_ctx.c:218-241`).

### Minors (non-blocking)

- `cfn_wait_for_change_set` doc claims `ECANCELED` for a deleted change set, but
  the underlying `ENOENT` propagates instead (`core/cfn/cfn.h:376-378`,
  `core/cfn/cfn.c:2036-2039,839-865`).
- Over-capacity field copy overflows fatally through `EOVERFLOW`
  (`core/cfn/cfn.c:515-532`).

## (ii) Cross-lane interface consistency — PASS

- Module symbol prefixes are applied consistently and no duplicate public
  symbols were found across wave-3 libraries.
- The `cli.h` include scheme is coherent: `core/cli/common` is the Bazel
  package, the canonical header is exported with `strip_include_prefix`
  (`core/cli/common/BUILD.bazel:13,22`), the eight frozen verb prototypes are
  present (`core/cli/cli.h:260-267`), accessors (`core/cli/cli.h:209-227`), and
  table/find/names helpers (`core/cli/cli.h:237-257`).
- Modules build on the amended seams rather than bypassing them: extra-header
  validation/signing in `core/aws/request.c:249-300` and sorted canonical
  headers in `core/crypto/sigv4.c:345-380`.

### Minor (forward hazard for wave 4)

- `cli_rc_to_exit` maps `ENOENT/EACCES/EPERM/ENOMEM` to `CLI_EXIT_USAGE`
  (`core/cli/common/cli_output.c:69-79` vs `core/cli/cli.h:62-69`,
  `core/cfn/cfn.h:22-24`): an AWS error surfacing as those errno values could
  exit 1 instead of the frozen 2. Recorded as a wave-4 integration risk.

## (iii) Error-handling — PASS

- No unchecked allocations found in the wave-3 modules.
- Frees on all paths in the sampled high-risk flows: `ec2_run_instances`
  (`core/ec2/instances.c:176-201`), `s3_call` (`core/s3/s3.c:456-472`), and
  `ssm_get_parameter` (`core/ssm/ssm.c:290-345`).
- Pagination and polling are bounded (waiter attempt/interval caps); out-params
  are respected; no secrets are printed (redaction cited above; SSM/DDNS
  passwords never logged).

### Minors (non-blocking)

- Repeated non-repeatable booleans are accepted although the header documents
  rejection (`core/cli/common/cli_args.c:67-88` vs `core/cli/cli.h:86-89,128-130`;
  test `core/cli/common/cli_args_test.c:121`).
- S3 returns NULL for an empty `<Key />` (`core/s3/s3.c:210-213`).
- SSM `last_modified` is only copied when the value is a string
  (`core/ssm/ssm.c:340`, `core/ssm/ssm.h:71`).
- SSM region truncates instead of rejecting (`core/ssm/ssm.c:47` vs
  `core/ec2/ec2.c:27-30`).
