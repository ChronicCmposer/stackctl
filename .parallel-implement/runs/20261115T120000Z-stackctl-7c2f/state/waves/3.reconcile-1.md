## Lane assumption reconciliation

- **w3-cfn** — in-module XML DOM parser + Query protocol, pagination, idempotent
  deletes, and `aws_wait` waiters accepted; all sit on `core/aws` only.
- **w3-ec2** — client struct seam, explicit one-time spot, required
  `root_device_name`, caller-decided zero-image DescribeImages, `EC2_ERR_AWS_API`
  (121/EREMOTEIO), console NULL when empty, AMI resolution owned by
  callers/ssm accepted; none changes the frozen surface.
- **w3-s3** — single PUT (no multipart per §5.5), `.sha256` sidecar metadata per
  §7.1 (owed to the `aws_req` header limitation), no presign (future per spec),
  bucket subresource coverage accepted; consistent with §7.1/§7.3/§13.
- **w3-ssm** — `ssm_put_parameter` omitted (spec §9: stackctl never writes
  parameters; DDNS SecureString is manual), SendCommand/GetCommandInvocation
  exposed though wave-4 start/stop uses SSH, Amendment 5 wiring with
  `content_type` NULL to avoid a duplicate header accepted.
- **w3-cliapi** — Bazel package-boundary/symlink scheme, `--lock-timeout`
  default -1, status lockless, help/version with no project, and the option
  parsing policy (duplicate value flags rejected, booleans idempotent, short
  bundling rejected) accepted; waves 4/5 must depend on `//core/cli/common:cli`
  and `#include "cli.h"`.
