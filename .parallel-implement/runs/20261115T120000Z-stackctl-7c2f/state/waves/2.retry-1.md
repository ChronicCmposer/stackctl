## Scope per lane

### w2-ddns
- Replace `ares_getaddrinfo` with `ares_query(..., ns_t_a)` +
  `ares_parse_a_reply` on the `ARES_FLAG_NORECURSE` + `ARES_OPT_SERVERS`
  channel (authoritative-only; no hosts-file or RFC-6724 resolution path).
- NS discovery must read the nameserver set from `h_aliases` (never `h_name`)
  as returned by `ares_parse_ns_reply`.
- Reject empty / no-answer results.
- Exercise the public `dns_a_record` / `dns_record_exists` wrappers.
- Minors: empty-answer success path; wrapper coverage.

### w2-templates
- Parse INGRESS_TCP/UDP comma lists of `port[:cidr]` with correct port and
  CIDR expansion; do not default to `0.0.0.0/0`.
- Checker must fail closed on NODE_MAP / long-form intrinsics for `Action` and
  `Resource` (inspect through the template model rather than `scalar_count()`
  only).
- Cert policy must be conditional per enabled bucket module.
- Align PROJECT max length with config's computed per-region bound.
- Require `ReleasePrefixes` only when a CI user is enabled.
- Isolate negative fixtures so each violates exactly one rule.

### w2-awsclient
- Strip `AWS_*` unconditionally, even when credential load fails.
- Reuse `core/ini` instead of hand-rolled INI parsing (or document and
  cross-test divergence if `core/ini` lacks a reader — prefer a small adapter
  over duplicate parsing).
- Do not classify `InvalidSignatureException` as clock skew.
- Add `curl_global_cleanup` in `aws_free`.
- Retry only transient transport errno.
- Enforce the credential-file size limit and check `ferror`.
- Restrict redirect protocols in `ddns_curl`. The ddns fixes belong to
  `w2-ddns`; `w2-awsclient` must not edit `core/ddns` — coordinate with
  `w2-ddns` instead.
