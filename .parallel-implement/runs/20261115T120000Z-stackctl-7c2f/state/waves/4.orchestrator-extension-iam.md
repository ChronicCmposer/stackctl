# Wave 4 — Orchestrator-Directed Extension: IAM/STS service module

## Decision

Create a new service module `core/iam/**` (AWS IAM + STS Query-protocol client)
as an orchestrator-directed extension outside the original frozen lane map.

## Rationale

Independent review `state/waves/4.review-1.md` found that provision and deploy
call `aws_request`/STS directly (defect ii), violating the contract rule that
only `core/cfn`, `core/ec2`, `core/s3` and `core/ssm` may reference the AWS
request seam. No existing service module covers STS identity or IAM access-key
operations, and wave-4 verbs must not open the transport themselves. The
operator therefore authorized a dedicated module, consumed by both re-tasked
wave-4 lanes.

## Exception to the WAVES lane map

- This is **not** a wave and **not** a lane. `WAVES.md` is unchanged.
- The extension is owned by this orchestrator-directed coder; that ownership is
  **dormant afterwards** (no wave-4 lane writes `core/iam/**`; only a future
  orchestrator-directed extension may reopen it).
- The exception is recorded in `state/waves/4.retry-1.md` and frozen as
  `CONTRACT.md` Amendment 6.
- `core/aws`, `core/crypto`, `core/cli`, `deploy/**` and every lane record were
  not modified.

## Interface pointer

`CONTRACT.md` **Amendment 6 — IAM/STS service module (orchestrator extension)**
freezes `core/iam/iam.h` exactly:

```c
typedef struct iam_key {
    char *user_name;
    char *access_key_id;
    char *secret_access_key;  /* NULL except for iam_create_access_key results */
    char *status;             /* "Active"/"Inactive" */
    char *create_date;        /* ISO-8601 as returned */
} iam_key;

int iam_get_caller_identity(aws_ctx *ctx, char **out_account, char **out_arn, char **out_user_id);
int iam_list_access_keys(aws_ctx *ctx, const char *user_name_or_null, iam_key **out, size_t *out_count);
int iam_create_access_key(aws_ctx *ctx, const char *user_name_or_null, iam_key *out);
int iam_delete_access_key(aws_ctx *ctx, const char *user_name_or_null, const char *access_key_id);
void iam_key_free(iam_key *key);
void iam_keys_free(iam_key *keys, size_t count);
```

Semantics: Query protocol over the frozen `aws_request` seam (`"sts"`/`"iam"`,
`us-east-1`); NULL user name = caller's own user; positive errno-style errors
with AWS error text on stderr (no secrets); secret only in create results;
out-params untouched on failure; all heap fields released by the free
functions; callers zero-initialise `iam_key` before create.

- `core/iam/iam.h` — frozen public interface + doc comments.
- `core/iam/iam_internal.h` — API versions, transport seam, body-builder decl.
